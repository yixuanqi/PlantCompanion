# v0.5 新版小蘑菇资源非破坏性集成

- **输入工程**：用户上传 `PlantCompanion_v0.3.rar`（其内部 package version 0.4.0）；保留完整 Rust 生命逻辑、数据库结构、默认 capability。
- **新资源**：`public/plant-assets/mushroom_v2/{healthy,sleep}/{pot,stalk,cap,foliage,composite}.png`，从原始 SVG 分层母版导出的 694×736 RGBA，未用旧概念拼图抠图。
- **打开方式**：正在种小蘑菇时，从挂件 `⋯` 菜单选择「预览新版小蘑菇」；再次选择回到旧版。仅更改渲染资源与浏览器 localStorage 选择，不写入 Rust Game/SQLite。
- **状态回退**：仅 healthy/sleep 有 v2；thirsty/dry/critical/dead 使用旧版已有切片，避免缺图。旧版素材完全保留。
- **样式**：`src/widget-v04.css` 是挂件主样式覆盖表，尺寸现统一 320×390 CSS px，与 `tauri.conf.json` 一致；植物区域仍为 222×222，以免视觉缩放骤变。Rust 窗口吸附位置根据窗口真实物理尺寸计算，不再硬编码 300×336。
- **预览**：执行 `node scripts/build_preview.mjs` 后，从 `browser_preview` 起本地 HTTP server，通过设置窗口种小蘑菇，随后从小挂件菜单切换新旧原画。
- **已知限制**：新版是矢量分层风格测试，不等同最初目标水彩最终美术；四个缺水/死亡状态尚未生产；原生 Tauri 真机尺寸、透明框、图层运动尚需用户 Windows 现场检查。
- **严禁**：覆盖 `mushroom` 原始资源、修改植物死亡与睡眠规则、将当前素材标记为最终美术。
