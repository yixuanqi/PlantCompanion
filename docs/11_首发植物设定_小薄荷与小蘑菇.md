# 11｜首发两株植物的可执行设定

本文件针对**小薄荷、小蘑菇两株首发角色**，让美术绘制与程序动画在统一框架下保留性格区别。

## 小薄荷 / Mint

- `species_id`: `mint`
- 角色定位：轻快、喜欢微风，像一个陪你认真工作的绿色小伙伴。
- 主要识别：圆润鲜嫩的薄荷绿叶片、可见细叶脉、3–5 片突出大叶、略弯的青绿茎、浅米白圆陶盆带小芽图案。
- 禁止：五官、花盆“脸”、绿得发荧光、写实叶缘齿刺、每阶段重画不同盆。
- idle：左右叶尖错峰慢摆，主茎微小弹性，偶尔小叶轻颤；**不能整体花盆像钟摆一样左右晃**。
- THIRSTY：叶片向下偏转，叶尖变软，绿色微暗。
- DRY：叶中段向下弯，边缘浅黄；整体高度降低。
- CRITICAL：大叶几乎低垂，部分泛暖褐；动作很慢。
- DEAD：主茎弯折、叶片干枯，盆边少量落叶；不可逆。
- SLEEPING：叶片轻轻向内收拢，主茎稳定；睡眠 Zzz 仅作可关闭提示，不画“闭眼”。
- WAKING：大叶依次打开、轻轻回弹，再回到进入睡眠前的 HEALTHY/THIRSTY/DRY/CRITICAL 姿态。
- 水滴反馈：水滴沿叶缘流下→叶片轻向上舒展→短暂明亮闪光。若之前在 CRITICAL 可恢复 HEALTHY，但只能基于有效喝水事件；DEAD 不接收。
- 推荐台词：`“叶子有点软软的啦。”` / `“咕噜咕噜，又精神起来啦！”` / `“我收起叶子睡一会儿。”`

## 小蘑菇 / Mushroom

- `species_id`: `mushroom`
- 角色定位：安静、害羞、温柔，喜欢缩在小伞帽下。
- 主要识别：柔和珊瑚粉伞帽、奶白短柄、雾白点点、椭圆柔阴影；盆边少量三叶草和小白花做固定装饰。
- 禁止：伞柄上画眼睛/嘴巴；把花盆装饰小花画成表情；变成写实毒蘑菇、高光塑料 3D。
- idle：伞帽缓慢“呼吸”式微缩放（保持锚点），柄身轻微侧向弹性；比薄荷更安静。
- THIRSTY：伞帽略垂，伞缘下沉，白点稍暗。
- DRY：伞盖不再饱满，稍偏一边，柄开始弯曲。
- CRITICAL：伞盖明显塌陷、颜色从粉变浅褐，重心下移。
- DEAD：伞盖褐化并塌下，柄软弯，盆边装饰干枯；不要做恐怖腐烂。
- SLEEPING：伞盖稍向下合拢，好像收起小伞；保持睡前实际生命阶段区别，不一定每次都重回完整粉色。
- WAKING：伞盖逐渐撑开，短柄恢复原高度，最后轻轻晃一下。
- 水滴反馈：水滴落在伞帽并滚落，伞缘轻弹一下；蘑菇慢慢撑起小伞，回到 HEALTHY。
- 推荐台词：`“我的小伞好像垂了一点……”` / `“哇，伞帽又撑起来了！”` / `“晚安，我把小伞盖好啦。”`

## 双植物并排检查（美术硬门槛）

1. 画布尺寸、花盆占比、花盆盆口椭圆、底部阴影位置一致。
2. 线条粗细与颗粒纸张质感一致，整体光源同方向。
3. 5 阶段的失水力度表现一致：THIRSTY 的“稍垂”不能比另一株 CRITICAL 还严重。
4. 睡眠必须区别于缺水，动画入口明确；睡醒后必须保留睡前原本状态。
5. 同一套叶片/水滴/星点/落叶特效资源语言；粉色蘑菇的特效不能突然变另一画风。

## 本阶段有意不设计的内容

隐藏蘑菇、星空花、幽灵蘑菇、四叶草、多肉等都属于植物库扩展；这里不做详细资产，避免分散第一版精力。
