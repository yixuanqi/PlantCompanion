# 03｜窗口、交互与拟人对白规范

## 1. UI 结构

1. **植物窗**：透明背景、无系统标题栏。默认贴近主屏右下角任务栏上方，可拖拽、可锁定位置、可设置是否置顶。推荐默认整体可见内容 128×150 DIP（不是硬编码截图像素），支持 96/128/160 等倍率。
2. **手绘气泡窗**：在植物侧上方出现，尽量避开屏幕边缘、任务栏和常用交互区；不可长期遮挡鼠标。显示 3–6 秒可配置，可手动关闭；同类提醒去重。
3. **状态小卡**：悬停短时显示植物名、阶段、距提醒/死亡剩余有效活跃时间、今日有效确认次数；睡着时显示“正在休息，计时已暂停”。
4. **托盘菜单**：`我喝水了` / `让它睡一会儿` / `唤醒` / `暂停 1 小时` / `设置` / `种子铺` / `图鉴与纪念花园` / `隐藏植物窗` / `退出`。按当前状态启用或隐藏部分操作。
5. **设置独立窗**：侧栏或顶部导航 `通用` / `提醒` / `植物` / `种子铺` / `图鉴` / `纪念花园` / `外观` / `关于`。

## 2. 操作约束

| 交互 | 生效行为 | 注意 |
| --- | --- | --- |
| 单击活跃植物 | “我喝水了”，确认一个周期 | 需提供撤销误触或“点击确认”选项，可设置；快速连点不得刷币 |
| 单击睡眠植物 | 唤醒，不自动算喝水 | 新手引导需明确 |
| 单击枯死植物 | 纪念记录/重新种植提示 | 没有复活路径 |
| 悬停 | 轻卡片展示状态，不自动暂停计时 | 不遮挡原系统点击 |
| 拖拽植物/拖动柄 | 改变屏幕相对位置并记住 | 和单击手势用位移阈值区分 |
| 右键 | 与托盘菜单一致 | 关闭和暂停始终能找得到 |
| 设置更换品种 | 只为下一代选择种子；活跃实例不可变种 | 不允许绕过死亡机制 |

## 3. 拟人台词的核心风格

- 植物没有五官，但**会说话**；角色声音来自气泡，不在植物身上画嘴。
- 语气温暖、俏皮、偶尔撒娇，但不能羞辱用户或暗示健康风险；避免“你不喝水我就死给你看”。
- 每条原则上 6–20 汉字，最多两行；对话无需配音；同句短时间不重复。
- 文案随阶段、角色和情境变化；一个小时最多主动弹若干次（建议 <=2），在系统全屏、勿扰、睡眠时不主动出现。

## 5. 气泡与面板视觉准则

- **气泡**：奶油白或极浅杏色底，低对比深棕绿文字，细微手绘不规则圆角与短尾巴；轻纸张纹理、柔和投影。
- **提醒重要度**：健康淡绿边、缺水暖黄边、濒死柔陶橘边、睡眠雾蓝紫边；禁用高饱和闪烁。
- **字体**：正文优先高可读中文字体；可在标题/短文案使用授权手写风字体，**不要依赖用户设备中存在某个字体**。不内嵌未授权商业字体。
- **布局**：浮窗内容在小尺寸仍可识别；气泡默认最大宽度 220–260 DIP；不透过背景泄露正文可读性。
- **动画**：气泡弹出使用 150–250ms 缩放 + 淡入；启用减少动态效果时立即显示而不缩放弹跳。
- **音效**：v0.1 默认关闭；不在专注、睡眠、全屏前台应用时发声。

## 6. 设置菜单的睡眠部分

- 自动睡眠：开/关；无输入超时：5/10/15/30 分钟（默认暂定 10）。
- 锁屏自动睡眠：默认开；系统挂起自动保护：始终开启。
- 活跃时段：默认 08:00–22:00，可自行调整；非活跃时段保护开关默认开。
- 手动睡眠：直到手动唤醒/1 小时/今天结束。
- 唤醒方式：Windows 会话恢复或用户返回后自动；也可点击植物唤醒。手动睡眠优先，不能被自动唤醒强制清除。
- 动画强度：完整 / 轻量 / 减少动态效果；与操作系统辅助功能设置协同。

## 7. 特殊屏幕问题

- Windows 任务栏位置可能变化；必须使用工作区 `work area` 和 DPI 感知坐标，而非硬编码“右下角 1920×1080”。
- 多显示器、任务栏自动隐藏、缩放 125%/150%、Remote Desktop、Windows 休眠恢复要真实测试。
- 游戏/演示/全屏窗口前，建议自动隐藏或降低置顶；避免妨碍工作。
- 透明窗口的可见像素边界和实际点击命中区可能不同，必须专门测，不能假设 CSS `pointer-events:none` 足够解决整个原生窗的穿透。
