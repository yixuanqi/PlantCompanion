# 05｜动画规范与美术资源合同（不是只做静态图）

## 1. 设计原则

无五官 ≠ 无动画。对本产品，动画的优先级为：

**idle 生命感 > 状态渐变 > 喝水反馈 > 睡眠/唤醒 > 成长彩蛋**。

采用**少量分层关键姿态 + 程序化 2D 动画**：植物主体与花盆独立，叶片/伞盖可旋转，水滴/小光点可独立绘制；只在形变跨度大的节点补关键帧或专用局部插画。不要求每一帧完全手绘，但也不能只用整张图拉伸/旋转假装叶片摆动。

## 2. 基础动画清单

| 动画 ID | 时间建议 | 可循环 | 小薄荷 | 小蘑菇 |
| --- | --- | --- | --- | --- |
| `idle_healthy` | 3–6s 循环 | 是 | 叶尖错峰轻摆、主茎幅度 1–3° | 伞帽轻呼吸 1–2%、短柄微弯 |
| `idle_thirsty` | 5–7s | 是 | 叶片低垂，偶尔小幅晃 | 伞帽略低、慢慢摆 |
| `idle_dry` | 6–9s | 是 | 叶片缓慢失弹 | 伞缘微收、停顿更久 |
| `idle_critical` | 8–12s | 是 | 几乎静止，低头 | 伞帽软塌，无跳动 |
| `transition_stage` | 0.7–1.5s | 否 | 叶角、颜色与局部形态插值 | 伞盖倾角、柄弯曲插值 |
| `water_recover` | 1.0–1.8s | 否 | 水滴→叶片抬起→轻回弹 | 水滴→伞盖抬起→恢复饱满 |
| `go_to_sleep` | 0.6–1.2s | 否 | 叶片靠拢、变安静 | 伞盖轻下压、微侧倾 |
| `sleep_idle` | 5–8s 循环 | 是 | 非常缓慢轻呼吸 | 伞帽非常轻微起伏 |
| `wake_up` | 0.7–1.3s | 否 | 叶片舒展、短回弹 | 伞盖撑起、柄微挺 |
| `grow_stage` | 1.2–2.2s | 否 | 小叶从芽中缓缓展开 | 小蘑菇柄伸展、伞盖变大 |
| `death_once` | 1.2–2.0s | 否 | 叶片缓垂并落下一片叶子 | 伞盖塌下，小叶落地 |

所有时长均为**目标区间，需实机视觉检查**；减少动态效果时以短淡入/静态替代，不影响业务状态。

## 3. 动画状态机与冲突仲裁

- Rust 输出 `life_stage` / `activity_mode` / `app_events`；前端动画组件自行决定播放，不回写业务计时。
- 动画优先级建议：`death_once` > `go_to_sleep/wake_up` > `water_recover` > `transition_stage` > `grow_stage` > `idle`。
- 睡眠不能被浇水特效中途强制打断而误记水；`water_recover` 入账后如果立刻锁屏，可结束当前帧并转入 `go_to_sleep`，但不重复入账。
- 进入 `DEAD` 后只能播放一次死亡动画；再次渲染只展示死后静态插画，不重复掉落叶子。
- 随机 idle 使用固定种子或限频方式，避免每次重绘随机抖动；任一动画帧不得触发钱包变动。

## 4. 分层资产合同（从“母版”拆分）

```text
species/mint/
  manifest.json               # 图层尺寸、锚点、姿态、动作定义、版本
  base/
    pot.png                    # 花盆，透明底，不带表情
    soil.png                   # 土壤，不覆盖植物前景
    stem.png                   # 主茎
    leaf_left_01.png           # 单独叶片，统一描边材质
    leaf_right_01.png
    leaf_center_01.png
    foreground_decor.png       # 少量土边叶，固定位置
    ground_shadow.png
  poses/
    healthy.json               # 图层角度/缩放/色相/可见状态
    thirsty.json
    dry.json
    critical.json
    dead.json                  # 可允许额外专用枯枝图层
    sleep_overlay.json         # 叠加姿态，不替换实际 life_stage
  fx/
    water_drop.png
    sparkle.png
    falling_leaf.png
```

小蘑菇至少拆分 `cap.png` / `stem.png` / `pot.png` / `soil.png` / `cap_spot_overlay.png` / `ground_shadow.png`，可按动画需要拆分伞缘与伞心。

- 统一画布推荐 512×512，**图层透明、保留位置与锚点**。不同文件不应该单独裁得紧到失去原始坐标。
- 所有层必须可追溯到单株母版，保留可编辑源文件（如 PSD/Krita/SVG 分层）与批量导出脚本。
- 需要在 96/128/160 DIP 预览版验证缩放锐度，不能以 512px 局部特写代替桌面实际效果。
- 精灵图不是强制；若采用帧序列，需 manifest 标识 `fps`、循环段、帧名、起止姿态、锚点。

## 5. 各个生命阶段的差异资产

| 阶段 | 必需额外美术素材 | 推荐实现 |
| --- | --- | --- |
| HEALTHY | 标准母版姿态 | 程序化微摆 |
| THIRSTY | 低垂关键姿态（可角度配置） | 0.7s 形态插值 + 低饱和 |
| DRY | 下垂/变黄关键姿态 | 插值+叠色，必要时重画弯叶 |
| CRITICAL | 严重枯萎姿态 | 1s 过渡与明显姿态变化 |
| DEAD | 专门静态死亡母版 | 一次性死亡过渡+静态常驻 |
| SLEEPING | 每株一套自然收拢姿态 | 不改变当前阶段资源，叠加睡眠偏移/弱光 |
| WAKING | 不额外派生生命阶段 | 从叠加状态插值回睡前阶段 |

## 6. 气泡与动画统一

- `bubble_background`：奶油纸底、轻手绘不规则边、低强度投影、短尾巴；对话气泡优先 HTML/CSS 布局，以容纳动态台词。
- 气泡弹出不超过 250ms，不弹跳过强；与植物的“轻轻呼吸感”一致。
- 水滴特效为同一蓝色系、同线条粗细；闪光小而稀疏；Zzz 不能独占屏幕。
- 夜间可换雾蓝遮罩，但植物在夜间不是直接变蓝色模型。

## 7. 制作流程与验收

1. **先画两株完整健康静态母版**（大小、视角、花盆、线条检查）。
2. 各拆关键层，分别做 2 个健康 idle 动作，真机验证“自然”和“性能”。
3. 做两株 `THIRSTY/DRY/CRITICAL/DEAD` 关键姿态，统一校色。
4. 做健康↔缺水、喝水恢复、死亡一次性、睡眠→唤醒转场。
5. 最后补粒子、掉落叶与气泡。
6. 全部动作输出对比预览：96px/128px/160px + 浅壁纸/深壁纸 + 60fps/30fps。

**资产验收条件**：不凭空增加五官、不重绘不同形制的花盆、同角色跨帧不跳位、睡眠和缺水不混淆、角色轮廓在小尺寸清楚、死后不能被前端复原状态。
