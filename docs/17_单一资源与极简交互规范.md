# 17 · 单一资源与极简挂件交互规范 (v0.7)

## 源资源
- `assets/species/mushroom/source` 是唯一可编辑 SVG 母版；`public/plant-assets/mushroom` 是唯一运行资源树。
- 4 图层 pot / stalk / cap / foliage，所有状态画布 694×736 RGBA，花盆在六态保持完全一致；另有 `states/*.png` 用于设置/图鉴缩略图。
- 禁止从概念拼图抠取子角色、对旧 PNG 多次去白边、给花盆添加五官。
- 目前 healthy/sleep 属于真实母版，thirsty/dry/critical/dead 是色彩和轻微形变派生稿，后续应由同一画师进一步精修，但 **不能恢复旧蘑菇图片作为回退**。
- 如需重画，先更新原生 SVG，再统一重新导出四层及完整图；保持文件名和画布坐标不变。

## 极简交互
- 常驻 UI 只显示植物；不显示常驻状态条、三点按钮、拖动按钮。
- 左键点击植物代表喝水；睡眠期间第一次点击仅唤醒。枯死点击打开种子铺，用户自行决定是否种新植物。
- 右键植物打开菜单：喝水、手动睡眠、休息 1 小时、唤醒、种子铺与设置、隐藏窗口。
- 鼠标在植物上停留约 650ms，才显示轻量手绘状态提示。拟人气泡只在必要的动作或状态变化显示。
- **左键按住植物移动超过 7px** 移动原生窗口；滚轮缩放 50%–100%，Ctrl+滚轮调整植物透明度 25%–100%；以上操作只在可见植物区域生效，不注册全局快捷键；任务栏托盘保留“显示、设置、睡眠、唤醒、退出”等。
- 挂件尺寸 268×292。Windows `shadow:false`；不应出现矩形边框。菜单必须在窗口范围内打开。

## 验收门槛
1. 从六种状态进入实际 Windows Tauri 挂件，绝不产生缺图/旧图闪回。
2. 花盆 idle 静止，菌柄/菌盖/叶子小幅局部摆动；DEAD 完全静止。
3. 状态提示与气泡不越界，主视觉不被截断，黑白背景透明边缘自然。
4. 100/125/150% DPI 和锁屏、关机、睡眠恢复真机验证仍不可跳过。


## v0.7：外观参数持久化

- Native Rust 保存 `widget-view-v1.json`；与生命周期 SQLite 完全隔离。
- 实际物理窗口的逻辑尺寸为 268×292 乘以 zoom，缩放后按右下角锚定避免位置跳动。
- 渲染逻辑与图片资源保持单一路径；无新增/回退旧蘑菇资源。
- 当缩至 92% 以下，右键使用原生菜单避免手绘弹层被小窗口裁切。
