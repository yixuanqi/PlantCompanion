# 运动图层制作说明 v0.4

- `public/plant-assets/{species}/motion_layers/{state}/` 为真正 RGBA 的 **可编程运动图层**，画布统一 256x256。
- 原图根据花盆口与菌柄位置做像素互斥分区，图层按像素互斥分区，合成后 **视觉上还原原始状态图**（RGBA 合成通道最大误差约 6/255，缘于舍入），不会出现同一区域重复贴图导致重影。
- 绘制顺序：`pot → stem → crown`。初始对齐严禁分别缩放/移动图层。
- CSS 锚点：薄荷叶冠 (50%, 69%)；蘑菇菌盖 (50%, 54%)、菌柄 (50%, 70%)。因为整张画布锚点相同，不使用 DOM 自动居中重新裁切。
- 当前是工程用运动分区，并非专业画师手绘的独立遮挡/背面素材。极限摆动仍可暴露细微切线，因此每个器官摆幅控制在 ≤1.4°，最终发布需原生分层原画。
- 六种阶段均有图层，DEAD 不播放 idle，sleep 仅微动；不可逆死亡与动画资产解耦。
- 边缘评估需要在浅色/深色桌面以及 100/125/150/200% DPI 下检查。
