# 00｜项目总览与开发约定

## 1. 产品定位

**桌面小植物（内部代号：Plant Companion）**：Windows 右下角轻量桌面陪伴工具，用可爱手绘植物承载喝水提醒和养成收集。

主体验是「看见植物 → 意识到可以喝口水 → 自主确认已喝水 → 看到植物恢复精神」；**不是**医疗饮水管理工具、传统番茄钟、电子宠物聊天机器人。

核心体验约束：低打扰、无需网络、打开即用、便于一键记录、不可逆死亡的情感张力与对真实生活的公平性同时存在。

## 2. 范围（MoSCoW）

### P0｜必须交付

- Windows 10/11 桌面右下角的透明无边框植物窗，默认任务栏工作区上方；支持 DPI、多显示器至少主屏。
- 小薄荷与小蘑菇两种首发植物；同一时刻仅养一株；前后台状态同步。
- 生命周期 5 个活跃态：`HEALTHY` / `THIRSTY` / `DRY` / `CRITICAL` / `DEAD`。
- `SLEEPING` 作为保护叠加状态，`WAKING` 作为**视觉过渡**；睡眠期间时间与成长进度冻结，死亡不可复活。
- idle 待机、缺水过渡、浇水/喝水恢复、入睡、唤醒的可辨动画。
- 点击植物确认「我喝水了」，有交互防抖和防刷机制；恢复动画和新周期。
- 弹出手绘风格短气泡，拟人台词，不画五官。
- 系统托盘 + 设置（提醒间隔、活跃时段、自动睡眠、显示、动画强度、开机启动可分步）。
- 本地可靠持久化；崩溃/重启/关机/睡眠不误伤植物；历史生命记录永久可查。
- 种子铺/图鉴/纪念花园最小闭环：解锁品种、选择下一代、查看历史；无真实支付。
- 自动化测试覆盖边界时钟、休眠、不可逆死亡与钱包防刷。

### P1｜完成 P0 后增强

- 更多 idle 变体、季节/时段光效；音效可关闭，默认安静。
- 花盆样式解锁、隐藏款解锁系统（先配置化，首版不制作隐藏款美术）。
- 动画资源编辑/打包工具、备份恢复、周报和导出图片。
- 更完整的无障碍操作、屏幕阅读器支持与减弱动画。

### 明确不做（v0.1）

- LLM 聊天、语音助手、云端同步、账号系统、多人排行、付费内购、饮水毫升数推断。
- 超过两种植物的正式资产；复杂骨骼引擎；整套逐帧表情动画。
- 因用户关机、锁屏、系统休眠、明确手动暂停而导致植物继续死亡。

## 3. 非功能标准

- 每次点击响应目标 < 150ms（非动画全程）；允许硬件差异，需实测。
- 静置 5 分钟 CPU 平均目标 < 1%；内存目标 < 150MB；**仅为验证门槛草案，绝非已测得数据**。
- 不抢键盘焦点；浮窗不能覆盖托盘交互；桌面透明区域不能无故拦截鼠标。
- 用户可以关闭悬浮窗显示而不丢数据；从托盘恢复可用。
- 不含用户可识别资料的遥测；默认离线，不采集屏幕内容、键入内容或完整输入记录。

## 4. 交付纪律（Agent）

1. 修改逻辑前更新/增加对应测试，状态机为纯函数优先。
2. 需求未覆盖的情况查 `10_待讨论决策与默认值.md`，使用已声明的默认值；不自行创造惩罚机制。
3. 首发美术必须比照两张参考图、04 和 05 文档；任何五官都是回归错误。
4. 每个迭代必须交付：可复现变更、测试结果、UI 截图/录屏、已知问题与下一步。
5. 不能把概念图裁成正式动画资产交差；动画需要独立可编辑分层图。
6. 所有业务时间来自 Rust 统一时钟与活跃时长累积，前端倒计时只是投影。

## 5. 成功判据

新用户不用读帮助能在 30 秒内理解如何喝水打卡；一天使用过程中没有误死亡；两个植物在同一 UI 里有明显共同画风；睡眠唤醒无时间跳变；用户能分辨枯萎、恢复和睡眠的不同含义。
