# 04｜统一美术规范：两株植物，一个世界

## 核心美术目标

> 可爱、清新、手绘绘本、柔和、低复杂度、安静耐看，放到 Windows 桌面右下角仍然一眼能认出植物品种及状态。

首发两株：**小薄荷、小蘑菇**。表现形式是“真实植物被温柔地卡通化”，不是“长着植物头发的人物”。**植物本体与花盆都不出现眼睛、嘴巴、眉毛等五官**。拟人性来自植物动态和气泡对白。

## 1. 统一约束（所有资产必须遵守）

| 维度 | 强制约束 |
| --- | --- |
| 风格 | 2D 绘本 / 轻水彩 / 彩铅边缘；温暖、轻微纸张质感 |
| 线条 | 柔和深灰绿、暖棕色轮廓，不用纯黑粗边；线宽按视图尺寸一致 |
| 造型 | 圆润饱满，局部略夸张，叶/伞边不几何僵硬；保留物种识别特征 |
| 颜色 | 低到中等饱和、春日浅绿、奶油白、淡杏、柔粉、雾蓝紫；同状态维持统一的色调逻辑 |
| 光影 | 偏左上柔光，少量明暗层次与薄薄接触阴影；不做强 3D 渲染、玻璃拟态 |
| 花盆 | 相同透视与形制：矮圆陶瓷盆、温润米白/浅杏/浅绿，简单细小叶/花图样；不同盆允许主题纹样差异，不允许出现五官 |
| 视角 | 统一轻微俯视的正面 3/4 视角；花盆盆口椭圆宽高、土壤位置统一 |
| 复杂度 | 桌面 96 DIP 可读，叶缘微细纹理可在小尺寸省略，优先大形体 |
| 背景 | 正式角色透明 PNG/WebP/SVG（按生产路线选）；概念图中的室内场景不包含在角色图层里 |
| 禁忌 | 像素风、厚涂、塑料 3D、赛博霓虹、强高光、极细真叶、颜文字五官、写实腐烂 |

## 3. 两株共享的“角色比例合同”

- 统一逻辑画布：建议 512×512 透明画布，视觉中心 x=256；盆底参考 y≈455；盆口参考 y≈340（具体随角色重绘定稿）。
- 花盆占画布宽度约 40–52%，高度约 22–28%，相同花盆在不同角色中保持透视一致。
- 植物最大高度约 75–85% 画布，留顶部 5–10% 动画空间；不要每个植物重设整体坐标基线。
- 阴影/掉落物限制在画布内；气泡、系统 UI、远景环境图绝对不能烘焙到角色本体图层。
- 不同动作中的花盆基本位置不变，植物可以轻摆、缩放、垂落；**不许出现跨状态花盆大小变来变去、形制漂移**。

## 4. 状态的共同视觉语法

| 状态 | 姿态 | 颜色 | 动态 |
| --- | --- | --- | --- |
| HEALTHY | 自然舒展，重心稳定 | 绿意鲜亮、暖粉清透 | 低幅度轻摆与呼吸节律 |
| THIRSTY | 叶或伞盖微垂 | 轻微去饱和 | 摆动幅度减小 |
| DRY | 明显下垂、收缩 | 叶缘发黄、花色暗淡 | 偶尔轻颤、静息增加 |
| CRITICAL | 几乎垂落、萎软 | 暖黄、枯褐加重 | 动作极慢，不做恐怖表现 |
| DEAD | 干枯低垂、掉叶或残伞 | 去生命色，暖褐灰 | 不可逆终态，整体静止，偶发落叶一次性 |
| SLEEPING | 收拢但**仍可看出睡前健康/缺水的主状态** | 罩一层极淡冷光，不改变本体图层颜色数据 | 极小幅度慢呼吸，可选月牙/Zzz 点缀 |
| WAKING | 舒展回睡前状态 | 恢复睡前本色 | 轻伸展、短暂停顿、继续阶段 idle |

尤其注意：**睡眠不是“枯萎”**。睡眠图以轻轻收拢、稳定的轮廓表达；枯萎图有重力下坠、颜色流失。两者缩到 96 DIP 仍要可辨。

## 5. 两株差异化

- **小薄荷**：嫩绿叶片、有细叶脉、短而略弯的茎；生命由叶片角度/弹性展现。枯萎以叶子垂下、泛黄体现。
- **小蘑菇**：柔珊瑚粉伞帽、奶白短柄、白点纹理、盆口边少量绿叶小花（装饰不是另一个角色）；生命由伞帽角度/厚度与柄弯曲展现。枯死伞帽塌陷褐化。
- 允许它们形态不同，但**花盆、绘画媒材、线条质感、阴影方向、状态配色、装饰特效风格必须一致**。

## 7. 交付前自检

- [ ] 完全没有五官，花盆图案也不像笑脸。
- [ ] 两株并排时像同一系列同一画师所画。
- [ ] 一样的花盆透视、描边粗细、接触阴影和暖色温。
- [ ] 96/128/160 DIP 均能认出状态，主要动作可辨。
- [ ] 全部状态使用同一角色母版形体；盆口、叶片或伞盖连接位置不漂移。
- [ ] 睡眠与枯萎明显可区分，死亡温柔而非令人不适。
