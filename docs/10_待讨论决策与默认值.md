## A. 已明确，不再摇摆

- [x] Windows 右下角透明小植物，轻量、打开就能用。
- [x] 首发仅小薄荷、小蘑菇；其他普通/隐藏款以后扩展。
- [x] 清新、统一、可爱、手绘绘本美术；**不做植物/花盆五官**。

- [x] 植物对白拟人，轻松可爱；气泡和 UI 同世界观。
- [x] 植物**个体死亡不可逆**，可保留纪念和图鉴，下代继续。
- [x] 用户离开电脑/休息时睡眠保护；**不扣成长与生命进度**，回来唤醒继续。
- [x] 种子铺、图鉴和隐藏款后续成长方向。

## C. 优先需要用户拍板的四件事

### 1）“枯死”的宽严程度

- **A 治愈优先（推荐）**：正常提醒 +20min 已确认活跃后死；明确空闲/睡眠的时间不计。
- B 硬核模式：死亡阈值更短；可在高级设置选择，但不作为默认。
- C 宽松模式：先进入休眠保护，不死亡；会削弱“不可逆”的情感张力。

### 2）枯死当天能不能重新种

- **已确认：用户自行决定什么时候种植；允许枯死后随时手动种植，但绝不自动种植**。
- 不可自动立即重种：植物枯死后保留枯死姿态与纪念入口，直到用户主动操作。
- 不设置强制冷却或次日限制。

### 3）如何启动种子铺的收集循环

- **A 首选一株免费，第二株 6 币**（建议）：能体验“收集获得”的乐趣。
- B 两款全免费：更轻，但首版商店只当图鉴/预告。

### 4）一天的活跃时段与无输入判定

- **A 每天 08:00–22:00 + 10min 无输入睡眠**（当前建议）。
- B 仅锁屏/系统休眠触发，避免看视频/阅读时误判。
- C 用户初次启动自行设置，略增加上手负担。
